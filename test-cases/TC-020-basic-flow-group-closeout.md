# TC-020 - Basic Flow Group Closeout

Version: 1.0 Draft
Status: Planned
Owner: Product / QA
Domain: Business Test Case Closeout
Related: TC-000-test-case-catalog.md

## Purpose

Close the first group of business test cases and define what the group should prove.

## Covered Range

```text
TC-001 to TC-020
```

## Group Purpose

This group validates basic intake behavior and common early routing situations.

## Expected Coverage

The group should cover:

- basic treatment story intake
- concern without clear consequence
- human review trigger
- delayed diagnosis concern
- dental treatment context
- missing documents
- old event timing
- childbirth context
- medicine reaction uncertainty
- extra care after treatment
- wrong area concern
- communication-only complaint
- unclear provider type
- unknown exact date
- available documents
- repeated question prevention
- unclear current consequence
- treatment abroad routing
- private provider routing

## Group Acceptance Checks

```text
conversation can start from varied user stories
known facts are stored
missing information is tracked
Smart Skip behavior can be validated
human review can be triggered
guide-away can be triggered respectfully
no final legal conclusion is claimed
```

## Definition of Done

```text
TC-001 to TC-020 exist
first business test group is complete
coverage themes are listed
acceptance checks are documented
```
