## Purpose

Create a catalog of reason codes used by the decision engine.

## Scope

- define MVP reason codes
- group codes by area
- document meaning of each code
- keep codes stable for logs and CRM

## Acceptance Criteria

- reason code catalog exists
- codes are grouped clearly
- each code has a short meaning
- codes can be referenced by tests and services

