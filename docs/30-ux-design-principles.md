# 30 - UX Design Principles

Defines the core UX principles for ErstatningsHjælp. These principles take precedence whenever a new flow or screen is designed.

## Core philosophy

The product should feel like a careful guided conversation, not a form and not a generic chatbot.

## Principles

1. Speak Human, Store Structured
- Users see natural language.
- The system stores structured entities.

2. Understanding Before Questioning
- Always demonstrate understanding before asking the next important question.

3. Confirm Before Classify
- Confirm the user's story before turning it into structured facts.

4. Never Ask Twice
- Never ask for information that has already been understood with high confidence.

5. One Thought Per Screen
- Each screen should have one purpose and one decision.

6. Guide, Don't Interrogate
- The experience should guide users through the process rather than feel like an interview.

7. Empathy Before Efficiency
- In serious situations, choose wording that builds trust over saving one interaction.

8. Always Allow 'Ved ikke'
- Users should never be forced to invent answers.

9. Collect Only What Matters Now
- Ask only for information needed for the current decision. Defer everything else.

10. Progressive Disclosure
- Start simple and reveal complexity only when needed.

11. Respect Emotional Context
- Death, severe injury and similar situations require calm, respectful wording.

12. Transparency Without Conclusions
- Explain what the system understands, but never state legal conclusions or promise outcomes.

## Design check

Every new screen should be reviewed against these principles before implementation.
