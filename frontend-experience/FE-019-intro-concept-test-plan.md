# FE-019 - Intro Concept Test Plan

Version: 1.0
Status: Active Draft

## Purpose

We will compare several first-screen concepts instead of only polishing one page.

## Goal

Find the intro direction that performs best on:

- clarity
- trust
- empathy
- simplicity
- accessibility
- mobile use
- confidence to start

## Concepts

### A - Digital Reception

A calm reception-like first screen. The user should feel that help is available immediately.

### B - Chat First Minimal

A very simple first screen focused almost entirely on writing the first message.

### C - Trust And Explanation

A clear first screen that explains what the service does, what happens next, and what the user does not need yet.

### D - Human Story

A warmer first screen that helps the user feel less alone and more comfortable starting.

## Test Questions

For each version, ask:

- Do I understand what this is within 10 seconds?
- Do I know what to do first?
- Do I feel allowed to be unsure?
- Do I understand that I do not need documents now?
- Does the page feel calm?
- Would an older user understand this?
- Would I write the first sentence?

## Scoring

Score each concept from 1 to 10 on:

- clarity
- trust
- empathy
- human feeling
- simplicity
- accessibility
- mobile usability
- first action confidence

## Decision Rule

The winning version is the one most likely to make a real user write the first honest sentence.

## Current Hypothesis

The strongest final direction may be a hybrid of:

- Digital Reception
- Trust And Explanation

## Done When

This phase is complete when:

- four concepts exist
- each concept can be reviewed
- one preferred direction is selected
- reasons are documented
