# FE-018 - Intro 10/10 Quality Bar

Version: 1.0
Status: Active Draft
Scope: Intro page quality target

## Purpose

This document defines what 10/10 means for the first intro page.

The intro page is not considered excellent because it looks nice. It is excellent only when a first-time user feels safe enough to start.

## Target Feeling

A user should think:

```text
I understand what this is.
I understand what I should do now.
I do not need to know the rules.
I can be unsure.
This feels calm and human.
```

## 10/10 Criteria

The intro page must score 10/10 on:

```text
clarity
trust
empathy
human feeling
accessibility
simplicity
mobile usability
```

## Clarity 10/10

The page answers within 5-10 seconds:

```text
What can ErstatningsHjaelp help with?
What should I write?
Do I need documents now?
Is this a final decision?
```

## Trust 10/10

The page must clearly communicate:

```text
free first start
no documents needed now
one question at a time
human review is possible
no guarantee or false promise
```

## Empathy 10/10

The AI must meet the person before the case.

Good:

```text
Tak fordi du fortæller det.
Det lyder som noget, der kan have fyldt meget.
Jeg hjælper dig roligt videre.
```

Avoid:

```text
Hvornår skete hændelsen?
Input received.
Case screening started.
```

## Human Feeling 10/10

The intro should feel like the start of a calm conversation, not a form.

Rules:

```text
AI speaks first
short chat-like messages
plain Danish
no legal jargon
no pressure
```

## Accessibility 10/10

Baseline:

```text
WCAG 2.2 AA
```

Practical requirements:

```text
large readable text
large buttons
visible focus
skip link
keyboard navigation
reduced motion support
clear labels
no color-only meaning
```

## Simplicity 10/10

The page must not ask for:

```text
CPR
login
document upload
legal category
hospital selector
long form
```

on the first screen.

## Mobile 10/10

A mobile user should be able to:

```text
understand the page quickly
read the AI welcome
write without layout problems
tap the primary button easily
continue the first question flow
```

## Manual Test

A test user should answer yes to:

```text
Do you understand what this service helps with?
Do you know what to do first?
Do you feel allowed to be unsure?
Does the page feel calm?
Would an older family member understand this?
```

## Current Gap To Close

The remaining work is mainly:

```text
more trust in the first viewport
more empathy in AI replies
more human chat flow
less form feeling
stronger accessibility polish
```

## Definition Of Done

The intro is 10/10 only when:

```text
a first-time user understands it without explanation
an older user can start without help
AI feels like a calm helper
trust signals are visible but not pushy
there are no confusing first-screen requirements
```
